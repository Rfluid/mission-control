# Brand

## Name

Always lowercase and hyphenated: **mission-control**, also at the start of a sentence and in titles. The CLI is `mission-control`, with the short alias `mctl`. In prose, "mission control" (two words) is the thing it gives you (the page); "a mission" is one tracked run. Don't write "Mission Control", "Mission", "MC" or "mc" (`mc` is Midnight Commander).

## Logo: the beacon

A watched signal in brackets: the agent works inside the frame, and the signal is what reaches you. The brackets are paper on an ink tile (ink on a paper tile); the signal is the `warn` tone, because the thing the page exists for is "something waits on you".

| File | Use on |
|---|---|
| `logo/wordmark.svg` | Light backgrounds: README header, docs |
| `logo/wordmark-dark.svg` | Dark backgrounds |
| `logo/mark.svg` | Ink tile: avatars, app icons, light UIs |
| `logo/mark-light.svg` | Paper tile, for dark UIs |
| `logo/favicon.svg` | 16–24 px: browser tab (served at `/assets/favicon.svg`). Heavier brackets, no halo |

- Generated by `logo/build.py` (letters outlined from Inter SemiBold, OFL). Never hand-edit the SVGs.
- Clear space: half the tile's width on every side. Minimum size: 16 px for the favicon, 24 px for the mark, 120 px wide for the wordmark.
- In the wordmark, "mission" is ink and "-control" is ink at a lighter weight only in the page header (`--ink3`, 500); the outlined SVGs keep one color.
- **Live favicon:** a mission page redraws the favicon with the signal in the mission's health tone, and a `warn` ring when needs are open (components.md, "Attention signals"). The static file stays warn.
- Don't recolor the brackets, add a second signal, animate the mark, or put it on a busy background.

## Voice and copy

- **Plain and short.** Sentence case everywhere ("Needs you", not "Needs You"). Section and tab titles are nouns.
- **Say what to do.** Empty states tell the user what fills them: "No missions yet. An agent starts one with `mission-control new "title"`."
- **Say why it's stuck.** A blocked record shows its reason in one line ("S3 credentials missing in CI"), and what it holds up ("holds R1").
- **Name the layer.** Config errors say which key and why (`sections[prs].widget unknown widget "x"`), never "something went wrong".
- **No exclamation marks, no emoji, no jokes in status.** The user may be reading this during an incident.
- **"You" for the user, "the agent" for the agent.** Never "AI".
